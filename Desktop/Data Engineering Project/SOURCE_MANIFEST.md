# Source and Evidence Manifest

All datasets in `data/` are synthetic demonstration data generated for this project. They contain no production customer information.

| Location | Purpose | Provenance |
|---|---|---|
| `data/sample/customers.csv` | Small reference customer dimension | Synthetic fixture |
| `data/sample/orders_day1.csv` | Initial-load example | Synthetic fixture |
| `data/sample/orders_full.csv` | Complete snapshot example | Synthetic fixture |
| `data/generated/orders.csv` | Larger generated workload | Deterministic generator; seed is recorded in generation command |
| `data/batch2/*.csv` | Later-batch and late-arrival examples | Synthetic fixtures |
| `data/scenario/` | Deterministic base, delta, partition-complete, expected-state and labelled QA scenario | Generated by `src/scenario_generator.py`; manifest includes seed and counts; labels are separate from pipeline CSV columns |

The pipeline records the absolute source path and SHA-256 digest for each run. `run_id` identifies an execution attempt; the digest identifies the exact input bytes. Reject rows retain their physical source-record number. Merge changes retain old/new values, source digest, run ID and source-record number.

Do not place production or personally identifiable information in the committed sample-data folders.
